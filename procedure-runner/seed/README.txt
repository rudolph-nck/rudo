Procedures to include with this copy of Procedure Runner.

Put exported procedures here (Library > ... > Export JSON, file name ending in .procedure.json).
The server adds each one to its data folder, published as v1, the first time it starts with that data folder.
Deleting a seeded procedure in the app is remembered (data/seeded.json), so it is not added again.

These files are not committed to git - they usually contain internal links and names.
